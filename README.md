## AeroAndes - Sistema de Reserva de Vuelos
Este repositorio contiene la estructura base y la interfaz web para AeroAndes, desarrollada como parte de una iniciativa académica y un proyecto colaborativo COIL.

# Características Principales
Buscador de Vuelos: Formulario interactivo para filtrar rutas especificando origen, destino, fecha de ida y cantidad de pasajeros.

Vuelos Disponibles: Tabla informativa que detalla códigos de vuelo, ciudades, horarios y tarifas (ej. rutas hacia Medellín y Cali).

Sección de Servicios: Resumen de beneficios para los pasajeros (equipaje incluido, check-in en línea, selección de asientos y atención 24/7).

Sección de Contacto y Acceso: Canales de atención al cliente y enlace directo al inicio de sesión.

# Tecnologías Utilizadas
HTML5: Maquetación semántica estructurada para una experiencia de usuario clara y accesible.
